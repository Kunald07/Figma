# 🎨 Figma Clone 

A lightweight, browser-based Figma-like design tool that allows users to visually create, edit, and export UI layouts with ease.

---

## 🚀 Core Features (Must-Have)

- **Figma-like, intuitive UI** for a smooth and familiar design experience.
- **Freestyle element creation**  
  Create shapes by selecting the square tool from the dock and dragging on the canvas.
- **Freestyle text creation**  
  Add text boxes by selecting the text tool from the dock and dragging on the canvas.
- **Smart element selection**  
  Select elements directly on the canvas or via the Layers panel.
- **Transform controls**  
  Drag, resize, and rotate elements effortlessly.
- **Layers panel**  
  Easily manage elements with move up/down controls.
- **Properties panel** to edit:
  - Height & Width  
  - Background Color  
  - Text Content  
  - Text Color  
  - Text Size  
  - Border Radius
- **Keyboard interactions**
  - Delete selected elements  
  - Move elements using arrow keys
- **Auto-save with Local Storage**  
  Ensures your work is never lost.
- **Export options**
  - Export designs as **HTML**
  - Export designs as **JSON**
  - Available via the Export button in the top-right corner

---

## ✨ Additional Features (Bonus)

- **Preset frame creation**  
  Create frames with predefined width and height using the Frame tool from the dock.
- **Editable file name**  
  Rename the default `Untitled` file by clicking the pen icon in the top-left corner.
